# Radar Comercial Once

Aplicación móvil para descubrir comercios en Once.

## Funcionalidades
- Buscar comercios.
- Explorar categorías.
- Ver comercios en mapa.
- Consultar por WhatsApp.
- Guardar favoritos.
- Navegar hacia el local con Google Maps.

## Stack
- React Native
- Expo
- Supabase
- Algolia
- Google Maps

## Navegación principal
- Home
- Buscar
- Mapa
- Favoritos
- Perfil

## Flujo de usuario
Abrir app → Explorar categorías → Buscar comercio → Ver perfil del comercio → Consultar por WhatsApp → Ir al local.
